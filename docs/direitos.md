# Direitos: o que podemos usar de graça (out/2026)

Resumo prático, não é parecer jurídico. As regras são das empresas e mudam: releia a fonte antes de lançar.

## Música
| Fonte | Pode? | Condição |
|---|---|---|
| Trilha sintetizada (`tools/trilha.py`) | Sim | É nossa. Padrão da fábrica. |
| Sascha Ende "Happy Beats / Business Moves" (CC BY 4.0) | Sim | Crédito no post: "Music: Sascha Ende, ende.app (CC BY 4.0)" |
| YouTube Audio Library, Pixabay Music, Mixkit | Depende | Conferir a licença de cada faixa (crédito, uso fora do YouTube) |
| Músicas em alta | Só no app | Escolher na biblioteca do TikTok/Instagram na hora de postar, nunca embutir no arquivo |
| Trilha original dos jogos | Não | Evitar |

## Vídeo
| Fonte | Pode monetizar? | Condição |
|---|---|---|
| Nossas animações (Remotion) | Sim | — |
| **Fortnite** (gameplay gravada pelo Tiago) | Sim, anúncios em vídeos web (ex.: YouTube) | Aviso obrigatório (abaixo). Nada de skins de parceria (Marvel, Star Wars, anime…), danças com música licenciada, menus/loja. |
| **Nintendo** (gameplay gravada) | Sim, pelos programas listados (YouTube Partner, bônus do Instagram…) | Precisa de input criativo nosso; não insinuar parceria com a Nintendo. |
| **GTA / Rockstar** | **Não pela política** | A política só permite uso não comercial. Vídeos de GTA: só com as nossas animações, sem imagens do jogo. |
| Minecraft | A confirmar | Ler a política da Mojang antes de usar. |
| Trailers e kits de imprensa | Arriscado | Pode gerar reivindicação (Content ID). Só trechos curtos dentro de comentário nosso. |
| Bancos grátis (Pexels, Pixabay, Mixkit) | Sim | Quase não há cultura pop. |
| Gameplay de outros canais | **Nunca** | Conteúdo reutilizado derruba a monetização. |
